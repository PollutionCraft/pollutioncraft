## Concerns for the reviewer
1. **Snapshot staleness:** an interval snapshots at its first tick and applies at its last; anything written to the field in between (a future `/pollution set`, task 009, or emissions applied directly) is overwritten for chunks in the job. Emissions (010) are buffered and drained at the snapshot, which is safe; 009 must go through `stepNow`/the scheduler or call `abandon()`.
2. **Dropped interval on error:** if `advance` throws (for example a bad capacity), `PollutionManager` logs and calls `abandon()`; the field is unchanged.
3. `emit`/`isAggressive` throw rather than silently doing nothing; no caller exists yet.
4. A future `dataVersion` is ignored and the next save overwrites it (data loss on downgrade). Brief says "skipped".
5. `PollutionDefaults` mirrors 008's starting defaults; switch to 008's config accessors when it merges.

## Downgrade protection (user decision, added after review)
An unreadable record is now kept and written back unchanged instead of being ignored and overwritten.
- `DimensionPollution.load`: a record whose `dataVersion` is missing, not an int, or not 1 is kept as the very `CompoundTag` that was read; `save` returns it unchanged. `isPreserved()` is true. Entry-level corruption inside a version-1 record is still skipped and logged (per architecture 3.2).
- `WorldPollution.load`: preserved when `dataVersion` is missing/unknown, `activeTicks` is not a long tag, `grossEmitted` is not a double tag, or the values are invalid (negative ticks, NaN/infinite/negative emitted). Missing keys used to read as 0 silently; that was the reset path.
- `PollutionManager`: a preserved world record stops `activeTicks` counting and the whole simulation (it logs an error at load); a preserved dimension is not simulated; `stepNow` does nothing for either. Nothing is merged into a preserved record. 010 must treat `isPreserved()` as "refuse writes".
- In-memory `record()` of a preserved world is a fresh record that is never saved, so `getPressure` reads 0 in that session (it already reads 0 until 016) while the stored `activeTicks`/`grossEmitted` stay intact.

## Round 3: Heimdall's re-review of the protection (3 items)
1. **Unparsable data file.** `WorldPollution.factory(Path)` / `DimensionPollution.factory(Path)`: Minecraft calls the factory constructor only when no record loaded, so the constructor now checks whether the data file exists. No file: normal fresh record. File exists but did not load (garbage, truncated, exception in our `load`): a **paused** record with no tag, one error log naming the file, `isDirty()` always false and `setDirty` ignored, `save` throws if ever called. The file path is `PollutionManager.dataFile(level, key)` (storage folder from `DimensionType.getStorageFolder` + `data/<key>.dat`); `loadWorld/loadDimension(storage, file)` are the entry points the manager uses and tests drive with a temp storage.
2. **No writable stand-ins.** `record()` / `field()` throw `IllegalStateException` on a paused record. `getPressure` and `getLocal` check `isPreserved()` first and return 0 ("paused", documented). The manager checks before touching either.
3. **`stepNow` result.** `PollutionManager.StepResult { RAN, PAUSED_WORLD_RECORD, PAUSED_DIMENSION_RECORD }`.
